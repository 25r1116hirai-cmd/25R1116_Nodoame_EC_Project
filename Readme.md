## 🛒 ショッピングの流れ（動作確認ガイド）
1. 商品を選ぶ

2. トップ画面の「おすすめ商品」や一覧から、気になるアイテムをクリックします。

3. カートへ追加

4. 商品詳細画面で「数量」を選び、[カートに追加する] ボタンを押します。

5. 注文情報の入力

6. カート画面へ進み、配送先の 「名前」「住所」 および 「クレジットカード番号」 を入力します。

7. 注文確定と確認

8. 決済完了後、ヘッダーの 「注文状況」 から、注文が正しく受け付けられたか確認できます。
